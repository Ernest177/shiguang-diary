# 关于我：把记录积累成可修正的理解

个人档案包含四个栏目：成长经历、记忆卡片、我的画像、月度回顾。它依赖用户允许的记录，并为理解保留依据；不通过生活评分衡量用户。

## 数据与授权

日记仍保存在原有表中。`memory_permissions` 单独记录长期记忆授权，旧记录默认不参与；补录经历保存在 `experiences`，默认不允许 AI。选择资料只改变本地授权，不立即发起模型请求。

用户点击“更新我的档案”后，先提取记忆，再生成画像，最多两次模型请求。单独画像和月度回顾各一次。相关任务持久化，但失败后由用户手动决定是否重试。云端服务的发送范围在页面确认中说明；不会自动发送整个人生历史。

经历时间保留用户原话，可写“大学期间”“大约2019年”。页面按补录时间排列，不伪造精确的人生时间线。月度回顾只采用以 `YYYY-MM` 开头的已授权资料；模糊时间经历仍可用于记忆与画像。

## 四条验收标准

| 标准 | 实现与检查 |
| --- | --- |
| 经历有出处 | 每张卡片有当前已授权原文的连续引用、来源 ID 和版本；伪造引用或未知来源会被拒绝 |
| 推测有标记 | 新画像归纳统一为待确认；仅逐字复述用户已确认 / 修正记忆时可显示原话确认。近期线索带时间范围；模式至少两条来源 |
| 纠正能保留 | 重整未修改来源时，用户确认和修正的卡片保留；同一引用产生的改写卡片会被拦截；画像使用修正文本 |
| 删除能生效 | 来源修改、删除或排除后，整个依赖记忆及缓存报告撤回；上下文签名和任务票据阻止在途旧结果写回 |

用户删除记忆后，仅保留标题类别指纹与来源引用哈希，防止相同标题或同一逐字引用重新生成；原文和已有历史备份不会被一并删除。这不是完善的语义遗忘：改变标题与引用表达后仍可能生成相似理解，需继续人工审阅。

来源一旦改变，依赖该来源的卡片连同其确认 / 修正一起撤回，避免把用户决定挂在已经失效的依据上。其他来源未变化的修正继续保留。

## 画像与月度变化

画像只引用有效记忆卡片，展示关注、价值、偏好、能力线索和仍在探索的问题。每项可以跳转到记忆与原文。引用存在不证明语义正确；不输出心理诊断、人格定论或人生评分，模型语义仍需人工核对。

月度回顾读取所选月份及上月的已授权资料。比较项必须同时有两个时期的引用；没有上月资料时只整理本月。程序能检查来源和时间覆盖，不能仅凭引用证明“成长”归纳正确，因此变化标为待确认。

记忆、画像和月度提示词分别登记版本与哈希；画像缓存保存模型、提示词信息、上下文签名和时间。任何相关来源或反馈改变都会清除旧报告；生成任务完成前再次核对上下文与票据。

## 升级、导出与恢复

数据库和 JSON 备份版本升级为 2。首次打开版本 1 数据库时，在 `data/upgrade-backups/` 中创建完整性检查通过的升级前快照，再执行事务建表。已有原文、历史、行动与 AI 设置保留；新授权默认空。

JSON 导出包含经历、记忆、来源、修正与遗忘指纹；Markdown 导出补充经历与当前有效记忆。恢复支持版本 1 / 2 的 JSON 与数据库快照。合并保留本机冲突与已有授权，恢复后个人画像和月度缓存撤回，由用户重新生成，避免使用过期上下文。

旧程序无法直接读取 v2 数据库。回退前先导出 v2 的新增记录，再结合升级快照恢复；当前没有一键降级向导，不应直接用旧数据库覆盖新数据。

## 验证范围

自动检查覆盖授权默认值、经历重复保存、纠正保留、确认与推测区分、遗忘、来源删除 / 修改 / 排除、在途竞态、月度双向来源、错误响应、迁移快照、旧版恢复、v2 导入导出和本机请求保护。前端使用合成状态检查渲染与转义。

11 个新增离线合约样例验证结构、引用、时间与待确认标记；使用手写响应，不能作为真实模型准确率。浏览器自动化工具当前不可用，本次未完成新的浏览器视觉与交互验收。真实 Aliyun 模型语义质量尚未评测。
